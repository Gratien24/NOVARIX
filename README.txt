NOVARIX v0.8 — RENDER STATIC SITE PACKAGE

Iyi package iteguwe gushyirwa kuri Render nka Static Site. Ifite index.html ku rwego rwo hejuru (root).

ICYITONDERWA CY'INGENZI:
- Render ntifungura ZIP nk'urubuga. Banza ushyire dosiye muri GitHub repository, hanyuma uhuze iyo repository na Render.
- Ikarita ikenera internet.
- Ikoresha OpenStreetMap standard tile service. Koresha mu buryo bworoheje, ntukore bulk download/prefetch, kandi wubahirize tile usage policy: https://operations.osmfoundation.org/policies/tiles/
- © OpenStreetMap contributors. Data is available under the Open Database License (ODbL).

UBURYO BWO GUSHYIRA KURI RENDER:
1. Kura ZIP (Extract All).
2. Fungura github.com, winjire muri konti yawe.
3. Kora repository nshya yitwa novarix-kcc (Public cyangwa Private).
4. Hitamo Add file > Upload files.
5. Fungura folder ya NOVARIX_v0_8_RENDER_READY kuri mudasobwa, uhitemo index.html na README.txt, ubishyire kuri GitHub.
6. Kanda Commit changes.
7. Fungura render.com, winjiremo.
8. Hitamo New + > Static Site.
9. Huza GitHub niba igusabye, uhitemo repository novarix-kcc.
10. Build Command uyisige ubusa; Publish Directory andika .
11. Kanda Create Static Site, utegereze deployment irangire.
12. Fungura URL Render iguhaye.

CONTROLS:
- W A S D cyangwa Arrow keys: kwimura umukinnyi.
- E: kwinjira/gusohoka mu modoka (banza uyegere).
- Subira kuri KCC: gusubira aho watangiriye.

Iyi ni prototype ya map-based gameplay, si umukino wa 3D wuzuye. Abantu n'imodoka ni ibigereranyo by'umukino.
